# I18N — Language switching and parallel documentation

AEGIS-EBS ships two independent layers of language support: the **dashboard UI** (runtime switch between Vietnamese and English) and the **documentation** (parallel Vietnamese and English files).

## 1. Dashboard UI: VI | EN button

- Open the dashboard (`http://localhost:5173`; start it with `bash scripts/demo-web.sh` or `cd aegis-dashboard && npm run dev`).
- In the header, click the **VI | EN** language-toggle button (accessible label: "Switch interface language"). The button toggles between `vi` and `en` — the other language becomes active immediately; no page reload is needed.
- Implementation: `aegis-dashboard/src/i18n.js` holds the `DICT.vi` / `DICT.en` entry tables built from one entry list (structural key parity). `setLang(lang)` updates the active language, writes the choice to `localStorage` under the key **`aegis.lang`**, sets `<html lang>`, and notifies subscribers; panels, reports, events and the Three.js HUD re-render their labels through `subscribe()` / `applyStatic()`.
- On startup `getLang()` reads `localStorage.getItem('aegis.lang')`; a valid stored value (`vi` or `en`) is used, otherwise the default is `vi`. The choice persists across reloads in the same browser profile. If `localStorage` is unavailable (private mode / security error / headless Node), the language still applies in memory for that session.
- Wire identifiers are intentionally NOT translated: `status/1`, `INCIDENT_EVENT`, EBSP/TLS names, `zoneCode`, severity values, command names and API field names stay identical in both languages.
- To reset: clear the `aegis.lang` key in browser devtools (or the site's storage) and reload; the UI returns to the Vietnamese default.

## 3. Translation policy

- English files are parallel translations, not replacements: numbers, runIds, commit SHAs, ports, commands, code identifiers, table/column names and file paths are preserved exactly from the Vietnamese originals.
- Every English file begins with `Language: English | Vietnamese original: <path>`.
- When figures change in a Vietnamese source, update both versions together; never "correct" a number in a translation independently.
- `docs/en/BAO-CAO-SUMMARY.md` is explicitly a condensed summary of the very long `docs/BAO-CAO.md`, not a full translation; consult the Vietnamese report for authoritative details.
